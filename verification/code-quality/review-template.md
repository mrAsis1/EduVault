# Code Quality Review Template

## Scope

What changed, in one or two sentences.

## Checklist result

Reference: `verification/code-quality/checklist.md`

- Passed: [count] / [total applicable]
- Failed items: [list or "none"]

## Review verdict

One of: **Approve** / **Approve with suggestions** / **Request changes**
(per `.github/instructions/review.instructions.md`) — stated explicitly,
not implied.

## Failed items — detail

For each Fail:

- **Item:** which checklist line
- **Where:** file/function
- **Why it matters:** concrete impact, not just "convention"
- **Resolution:** fixed in this PR / follow-up / accepted as-is with
  reason

## Reviewer

Name, date, score from `verification/code-quality/scorecard.md` if
tracked.
