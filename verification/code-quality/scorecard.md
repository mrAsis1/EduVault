# Code Quality Scorecard

## Scoring

For each checklist section (Naming, Review bar, Feedback quality):

- **2** — all applicable items pass
- **1** — minor issues with a follow-up
- **0** — unresolved or unflagged issues

**Total score** = sum of section scores / (2 × number of applicable
sections), as a percentage.

## Interpretation

- **100%** — clean naming and full review bar met.
- **70–99%** — minor issues, tracked; acceptable to merge.
- **Below 70%** — do not merge; review bar not met or naming drift
  compounding.
