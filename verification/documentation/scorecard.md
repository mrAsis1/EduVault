# Documentation Scorecard

## Scoring

For each checklist section (Structure, Duplication, Currency, Content
quality):

- **2** — all applicable items pass
- **1** — gap identified with a linked follow-up
- **0** — gap unflagged, especially any duplication across layers

**Total score** = sum of section scores / (2 × number of applicable
sections), as a percentage.

## Interpretation

- **100%** — no duplication, current, well-structured.
- **70–99%** — minor gaps tracked; acceptable to merge.
- **Below 70%** — do not merge; likely duplicating an existing canonical
  source (the ADR-0002 failure mode) or introducing stale/misleading
  content.
