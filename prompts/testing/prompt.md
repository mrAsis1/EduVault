# Testing: Prompt

```
Write tests for: [describe the code/behavior].

One behavior per test, named "should <expected behavior> when
<condition>". Cover happy path, edge cases, and error cases. Mock
external dependencies (network, filesystem, time). Do not test
implementation details.
```
