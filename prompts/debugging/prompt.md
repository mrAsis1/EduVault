# Debugging: Prompt

```
Diagnose and fix this issue: [describe the bug, include repro steps
if you have them].

Reproduce it first. Identify root cause before proposing a fix. Add a
regression test that fails before the fix and passes after. Do not
bundle unrelated cleanup into the fix.
```
