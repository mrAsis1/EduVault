# Debugging: Variants

## Reproduction not yet possible

```
I can't reliably reproduce this yet: [describe what's known]. Don't
guess at a fix — tell me exactly what's missing (logs, input,
environment, steps) before proposing anything.
```

Per [`.github/instructions/debugging.instructions.md`](../../.github/instructions/debugging.instructions.md)'s
"if reproduction isn't possible... state exactly what's missing" — this
variant makes that the explicit first output instead of a fix attempt.
