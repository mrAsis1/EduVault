# Notes

## Purpose

Informal working notes that don't yet fit `benchmarks/`, `experiments/`,
or `comparisons/` — a place to keep an idea from being lost while it's
still forming, without forcing it into a more structured format before
it's ready.

## When to add an entry

When you're thinking through something worth keeping but it's too early
for a hypothesis, a measurement, or a decision. If it later firms up into
one of those, move it and delete the note — don't let it linger
duplicated in both places.

## Format

One file per note: `[short-topic-in-kebab-case].md`, using
`note-template.md`. Looser than other templates here — the point is low
friction to capture, not polish.
