# Benchmarks

## Purpose

Measured performance comparisons with explicit methodology — the actual
evidence behind a performance claim, not the claim itself.

## When to add an entry

Any time a performance-motivated decision is made (a library choice, a
readability trade-off per `.github/instructions/performance.instructions.md`,
an infrastructure choice) — the benchmark backing that decision belongs
here, referenced from wherever the decision is recorded.

## Format

One file per benchmark: `[short-topic-in-kebab-case].md`, using
`benchmark-template.md`.
