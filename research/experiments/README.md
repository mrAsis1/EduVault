# Experiments

## Purpose

A specific hypothesis tested, with a recorded outcome — regardless of
whether the hypothesis was confirmed. An inconclusive or negative result
is still worth recording, since it prevents re-testing the same idea
later without remembering it was already tried.

## When to add an entry

Before starting any exploratory spike where the outcome will inform a
real decision — write the hypothesis down first, then record what
actually happened.

## Format

One file per experiment: `[short-topic-in-kebab-case].md`, using
`experiment-template.md`.

- `research/README.md`
