# Comparisons

## Purpose

Evaluating multiple options — tools, libraries, architectural
approaches — against explicit criteria, so the choice is a documented
decision rather than a preference nobody can reconstruct later.

## When to add an entry

Before adopting a new tool/library/approach where alternatives exist
and were seriously considered. If there was really only one reasonable
option, a comparison isn't needed — just record the choice where it's
used.

## Format

One file per comparison: `[short-topic-in-kebab-case].md`, using
`comparison-template.md`.

## Related MAW Documents

- `research/README.md`
