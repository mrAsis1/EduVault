# Lessons Learned

## Purpose

A specific insight gained from experience — independent of whether
anything actually broke. Distinct from `postmortems/`, which is
specifically about incidents; a lesson-learned can come from a success,
a near-miss, or just noticing something the hard way during normal work.

## When to add an entry

When you catch yourself thinking "I wish I'd known that before starting
this" — that thought is the entry.

## Format

One file per lesson: `[short-topic-in-kebab-case].md`, using
`lesson-template.md`.
