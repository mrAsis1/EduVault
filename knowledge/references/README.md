# References

## Purpose

Pointers to external standards, specs, or authoritative docs used as a
source of truth for something in this codebase — the kind of link you
want to cite in a PR instead of re-explaining from scratch every time.

## When to add an entry

When an external standard/spec is cited more than once, or when a
decision leans on an authority worth naming explicitly (e.g. "we follow
RFC 7231 here" rather than reinventing the rule).

## Format

One file per reference: `[short-name-in-kebab-case].md`, using
`reference-entry-template.md`.
