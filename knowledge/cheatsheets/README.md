# Cheatsheets

## Purpose

Quick-reference material for something used often enough that condensing
it saves real time — command sequences, common gotchas, or a compressed
version of a longer doc for fast lookup during active work.

## When to add an entry

When you or someone else looks up the same thing (a command, a
sequence of steps, a set of gotchas) often enough that a full doc read
each time is wasted effort.

## Format

One file per topic: `[topic-in-kebab-case].md`, using
`cheatsheet-template.md`. Keep it scannable — lists and tables over
prose.
