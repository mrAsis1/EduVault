# Articles

## Purpose

Notes on external articles, blog posts, or talks worth remembering —
shorter-lived and more specific than `books/`, often tied to a single
technique or a single decision rather than a broad philosophy.

## When to add an entry

When an article changed or justified a specific technical decision, or
when it's referenced often enough in conversation that it's worth having
a durable note instead of re-finding the link each time.

## Format

One file per article: `[short-topic-in-kebab-case].md`, using
`article-notes-template.md`.
